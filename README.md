🧮 MeetingCals

Welcome to the source code for MeetingCals, the free online tool that helps you calculate the true cost of meetings — in time and money — so teams can make smarter decisions about how they collaborate.

🌐 Live App: https://meetingcals.com

💡 About

MeetingCals was built to give professionals, managers, and teams a clear picture of how meeting time translates into real business costs.
It’s designed for simplicity, accuracy, and accessibility — offering instant insights with no sign-up required.
